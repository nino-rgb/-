# 02_仕様

- バージョン：v0.1（初版）
- 対象：vspolive Goリメイク版
- 状態：仕様合意済み・実装前（実装・検証に応じて更新）

## 1. サービスの目的と基本方針

vspoliveは、ぶいすぽっ！の各タレントの配信情報をYouTube・Twitchから集約し、まとめて確認できるサービスである。リアルタイム性よりも情報の集約を優先し、取得・表示の遅延を許容する。

既存のExpress（TypeScript）版のユーザー向け機能を原則維持しつつ、Go版では既知の保存・削除上の問題を改善する。既存Reactフロントエンドを基本的に流用する。

> 本書は**Go版の実装予定仕様**を記す。チェックボックスは受け入れ確認項目であり、実装済みを意味しない。旧Express版の挙動と異なる箇所は必要に応じて注記する。

## 2. ユーザーストーリーと受け入れ条件

### 機能1：現在配信中のタレントを確認する

**ユーザーストーリー**

ぶいすぽっ！の視聴者として、現在配信中のタレントを一覧で確認したい。なぜなら、各タレントのYouTubeやTwitchを個別に確認する手間を減らしたいから。

**受け入れ条件**

- [ ] 現在配信中として登録されているタレントの配信情報を一覧表示できる。
- [ ] 配信のタイトル・サムネイル・日時を確認できる。
- [ ] 配信を選択すると、YouTubeまたはTwitchの配信ページへ移動できる。
- [ ] 1人のタレントについて表示される配信情報は最大1件である。

**旧版との差分：** 旧Express版では同じタレントの配信が複数保存される可能性があった。Go版ではタレントごとに最大1件となるようにする。

### 機能2：過去のYouTube配信を確認する

**ユーザーストーリー**

ぶいすぽっ！の視聴者として、各タレントの直近のYouTube配信をまとめて確認したい。なぜなら、タレントごとのYouTubeチャンネルを個別に確認せずに、見逃した配信を探したいから。

**受け入れ条件**

- [ ] YouTubeの過去配信情報を新しい順に一覧表示できる。
- [ ] 配信のタイトル・サムネイル・日時を確認できる。
- [ ] 配信を選択すると、YouTubeの該当動画ページへ移動できる。
- [ ] 新規アーカイブの保存時に、保持期間内の既存アーカイブが不必要に削除されない。
- [ ] 初期段階では最新30件を表示する。
- [ ] アーカイブの保持期間は原則14日間とする。

**運用上の方針：** 毎時のYouTubeアーカイブ同期でAPI取得・増分保存が成功した後、保持期間（14日）を過ぎたレコードを削除する。API取得または保存が失敗した場合、その回の期限切れ削除は行わない。日時の厳密な基準や処理順序は `references/同期処理仕様.md` で定義する。(別途後日追加予定)

**旧版との差分：** 旧Express版には新規アーカイブ保存時に同じタレントの既存アーカイブを削除してしまう問題がある。Go版では増分保存し、期限切れデータのみ削除する。

### 機能3：タレントを名前で検索する

**ユーザーストーリー**

ぶいすぽっ！の視聴者として、タレントの名前から目的のタレントを検索したい。なぜなら、一覧から探す手間を省き、目的のタレントの情報へ素早くアクセスしたいから。

**受け入れ条件**

- [ ] 配信中一覧・アーカイブ一覧・タレント一覧など、検索欄を設けたページから名前で検索できる。
- [ ] 入力文字列を名前に含むタレントが検索結果に表示される（部分一致検索）。
- [ ] 検索結果からタレントの詳細ページへ移動できる。
- [ ] 一致するタレントがいない場合は、検索結果がないことを確認できる。

**補足：** 検索欄の設置場所にかかわらず、検索対象はタレント名とする。誤字補正などの高度な検索は対象外。

### 機能4：タレントの情報を確認する

**ユーザーストーリー**

ぶいすぽっ！の視聴者として、現役・卒業済みを問わず、登録されているタレントのプロフィールやSNSを確認したい。なぜなら、過去に所属していたタレントも含めて、各タレントの情報や公式アカウントへ簡単にアクセスしたいから。

**受け入れ条件**

- [ ] 登録されているタレントを、卒業済みかどうかにかかわらず一覧表示できる。
- [ ] タレント一覧や検索結果から詳細ページへ移動できる。
- [ ] 詳細ページで名前・アイコンなどのプロフィール情報を確認できる。
- [ ] YouTube・Twitch・Xなど、登録済みの外部アカウントへ移動できる。
- [ ] 詳細ページでは、DBに保持されている直近14日間のYouTubeアーカイブを確認できる。
- [ ] 卒業済みタレントの新しい配信情報は取得しない。
- [ ] 卒業済みタレントのプロフィールや外部リンクは、アーカイブがなくなっても閲覧できる。

**補足：** アーカイブの14日間は**卒業日からではなく各アーカイブの日時から**数える。卒業状態はGo版で `is_active` により管理する予定。外部アカウント自体が削除された場合、リンク先の閲覧までは保証しない。

### 機能5：配信情報を自動的に更新する

**ユーザーストーリー**

ぶいすぽっ！の視聴者として、各タレントの配信状況や新しいアーカイブを自動的に確認したい。なぜなら、各配信プラットフォームを個別に確認したり、情報を手動で登録したりせずに、配信情報をまとめて把握したいから。

**受け入れ条件**

- [ ] YouTubeとTwitchの現在配信中の情報を自動取得できる。
- [ ] YouTubeの新しいアーカイブ情報を自動取得できる。
- [ ] 配信情報の取得処理が原則1時間ごとに実行される。
- [ ] 新しい配信情報が取得された場合、一覧表示に反映される。
- [ ] 配信終了後は、一定の確認を経て配信中一覧から除外される。
- [ ] 外部APIの一時的なエラーだけを理由に、既存の配信情報が削除されない。
- [ ] 卒業済みタレントは新しい配信情報の取得対象から除外される。

**補足：** APIクォータ節約を優先するため、配信開始・終了の反映遅延を許容する。終了判定に複数回の確認を要するため、終了後の表示が1時間以上残ることもある。具体的な取得・保存・終了判定は `references/同期処理仕様.md` で定義する。

## 3. やらないことリスト（初期リリースの対象外）

- Twitchの過去配信（アーカイブ）の取得・保存
- 配信情報のリアルタイム更新
- 14日間を超えるアーカイブの長期保存
- アーカイブ一覧のページング・無限スクロール
- 既存フロントエンドの大幅なUI変更
- 配信タイトルによる画面上の検索機能
- タレント情報を登録・編集する管理画面
- 誤字補正などの高度なタレント検索

## 4. 完成後の追加候補（優先度：低）

- **アーカイブ一覧のページング：** 1ページ30件とし、31〜60件を2ページ目に表示するなど、ページ単位で閲覧できるようにする。無限スクロールは採用しない。閲覧対象はDBに保持されている14日間の範囲とする。
- **管理画面：** 管理者認証・認可を導入し、タレントの追加・編集、卒業状態の変更などを管理できるようにする。削除操作の許可範囲は実装時に別途設計する。

初期段階では、タレントの追加・編集・卒業状態の変更はDBの手動操作で行う。
